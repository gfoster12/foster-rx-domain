Why this matters

An assistant that cannot tell you which register you are in will eventually be quoted as though it were certified.

That is the failure this design exists to prevent. The label is not a disclaimer someone remembered to add — an informational answer is structurally unable to carry a seal, because the certified component requires a certificate object and an unreviewed answer has none to give it.

Informational · unreviewed

Which families have a fee window inside ninety days. Which assets are blocked. What changed this week. Answered immediately, from the same records and the same registered methodologies, and labelled for what it is.

Certified · reviewed and signed

Send any answer for review. A qualified reviewer signs it and it issues as a certificate at a verifiable address your counterparty can open without an account. Same engine, same records — the difference is that a person put their name on this one.
