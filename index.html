Analysis is cheap. Trust is expensive.

Inside a certified assessment

Seven parts. Twenty-five sections. Every gap stated.

Every certified assessment follows a ratified architecture, and every statement in one is classified by what stands behind it. Four conventions govern the whole document; the full part-by-part architecture ships in the specimen, not here.

Certificate record

Reproduced exactly as recorded from a signed source. Never paraphrased, never improved on.

Computed

Arithmetic over enumerated inputs, recomputable by anyone holding the same record. The computation is named.

Analytical

Reviewer synthesis, attributed and signed. Analysis is never presented as record.

Stated absence

Where the record supports nothing, the section says so and stays empty. A gap is rendered, never filled.
